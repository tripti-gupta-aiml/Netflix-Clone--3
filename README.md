# 🎬 Netflix Clone Website

A beginner-friendly Netflix-inspired website created as a first-year BTech CSE-AIML college project using HTML and CSS.

## 📌 About the Project

This project recreates the look and feel of Netflix's homepage. It includes a hero section, movie gallery, feature sections, frequently asked questions, and a footer.

The project is developed for educational purposes to practice frontend web development.

## ✨ Features

- Netflix-inspired homepage design
- Navigation bar with language selection
- Email input form with a Get Started button
- Attractive movie and entertainment sections
- Movie poster gallery with clickable cards
- Feature sections for TV, downloads, and viewing on different devices
- Frequently Asked Questions section
- Footer with useful links
- Responsive layout (depending on the CSS implementation)

## 🛠️ Technologies Used

- **HTML5** – Website structure
- **CSS3** – Styling, layout, and design
- **YouTube thumbnails and Unsplash images** – Visual content

## 📂 Project Structure

```text
Netflix-Clone/
│
├── index.html

├── movie.html
└── README.md
```

*Note: Include `movie.html` only if it exists in your project folder.*

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure `index.html` and `style.css` are in the same folder.
4. Open `index.html` in your browser, or use the Live Server extension in VS Code.
5. Explore the homepage and click on the movie cards.

## 🎥 Movie Gallery

The website includes a movie gallery with categories such as:

- Vivah
- Movie Night
- Family Movies
- Adventure Movies

Some cards link to YouTube search results, while the Vivah card links to the local `movie.html` page.
